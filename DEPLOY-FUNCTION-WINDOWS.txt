SBAS Student Portal - Cloud Function deployment (Windows)

IMPORTANT: The browser's 404 response means the callable Cloud Function URL currently does not resolve. The CORS warning is a consequence of the 404; it does not by itself prove that the CORS allowlist is wrong.

1) Install Node.js 20 LTS and Firebase CLI (one time):
   npm install -g firebase-tools

2) Extract this ZIP. Open Command Prompt or PowerShell in the extracted student-repo folder (the folder containing firebase.json).

3) Run:
   firebase login
   firebase use sbas-2bfe2
   cd functions
   npm install
   cd ..
   firebase deploy --only functions:studentPortalLogin

4) Wait for a successful deploy message. In Firebase Console > Functions, confirm studentPortalLogin exists in us-central1.

5) Open https://sonarbanglaadarshoschool.github.io/student/ in a private/incognito window and test again.

Billing: Deploying Cloud Functions may require the Firebase project to be upgraded to the Blaze plan. Review Google Cloud/Firebase pricing and budgets before enabling billing.

Do not publish Firestore rules from this package without reviewing them against the existing admin dashboard's live rules. The 404 issue is fixed by deploying the missing function; rules are a separate step.
